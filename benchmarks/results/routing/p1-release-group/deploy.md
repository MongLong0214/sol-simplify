# 첫 배포 절차

가정: 아직 코드와 배포 대상이 없다. 이번 주(2026-08-24~2026-08-30)의 목표는 최소 실행 화면을 공개 URL에서 확인하는 것이다.

## 범위

- 포함: 최소 실행 화면, 실행·빌드 명령, 운영 배포, 공개 URL 확인
- 제외: 스테이징 환경, CI/CD, 별도 모니터링 시스템

## 순서

담당자는 전 단계 모두 프로젝트 소유자 본인이다.

1. 배포할 서비스 하나를 정한다.
2. 최소 실행 화면과 필요한 실행·빌드 명령을 추가한다.
3. 로컬에서 실행해 화면이 열리는지 확인한다.
4. 선택한 서비스에 프로젝트를 만들고, 필요한 환경 변수가 있다면 등록한다.
5. 운영 환경에 한 번 배포한다.
6. 시크릿 창에서 공개 URL을 열어 화면이 정상 표시되는지 확인한다.

## 롤아웃과 롤백

사용자가 아직 없으므로 운영 환경에 1단계로 공개한다. 공개 URL이 열리지 않거나, 5xx 응답·빈 화면·핵심 동작 실패가 확인되면 즉시 롤백한다. 이전 성공 배포가 있으면 그 버전으로 되돌리고, 첫 배포라면 공개를 중지한 뒤 수정해 다시 배포한다.
