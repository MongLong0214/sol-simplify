# 첫 배포 절차

전제: 현재 코드가 없고 배포 플랫폼도 정해지지 않았다. 이번 주에는 최소 실행 가능한 버전을 만든 뒤, 선택한 플랫폼의 기본 Git 저장소 연동으로 한 번만 배포한다. 모든 단계의 담당자는 본인이다.

## 배포 범위

- 포함: 실행 가능한 최소 기능, 실행에 필요한 환경 변수, 공개 URL
- 제외: 별도 릴리스 브랜치, 승인 절차, 단계적 롤아웃, CI/CD 자동화

## 절차

1. 최소 실행 버전을 만들고 로컬에서 실행한다.
2. 앱 유형에 맞는 배포 플랫폼 하나를 정한다.
3. 비밀값은 저장소에 넣지 않고 배포 플랫폼의 환경 변수로 등록한다.
4. 코드를 `main` 브랜치에 커밋하고 원격 저장소에 푸시한다.
5. 배포 플랫폼에서 저장소를 연결하고 빌드·실행 명령을 설정한다.
6. 사용자가 아직 없으므로 프로덕션에 한 단계로 공개한다.
7. 공개 URL에서 다음을 직접 확인한다.
   - 페이지가 정상적으로 열린다.
   - 핵심 기능 한 가지가 동작한다.
   - 배포 로그에 실행을 막는 오류가 없다.

## 완료 기준

공개 URL에서 페이지와 핵심 기능이 정상 동작하면 첫 배포를 완료한다.

## 중단 및 복구

공개 URL이 열리지 않거나 핵심 기능이 실패하면 즉시 공개를 중단한다. 첫 배포에는 되돌릴 이전 버전이 없으므로 문제를 수정해 다시 배포한다. 이후 배포부터는 같은 문제가 발생하면 플랫폼의 직전 정상 배포로 되돌린다.
