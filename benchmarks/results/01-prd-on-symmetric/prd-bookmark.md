# 게시글 북마크 기능 PRD

## 1. 목적

로그인 사용자가 나중에 다시 볼 게시글을 저장하고, 마이페이지에서 저장한 게시글을 모아 볼 수 있게 한다.

## 2. 범위

### 포함

- 게시글 상세 화면의 북마크 추가/해제 버튼
- 로그인 사용자별 북마크 저장
- 마이페이지의 북마크 목록 조회
- 로딩, 빈 목록, 실패 상태 처리

### 제외

- 북마크 폴더, 태그, 메모
- 북마크 수 공개 및 인기 순위
- 알림, 공유, 내보내기
- 관리자용 북마크 관리 화면

## 3. 사용자 흐름

### 게시글 북마크

1. 사용자가 게시글 상세 화면을 연다.
2. 로그인 상태라면 현재 북마크 여부가 버튼에 표시된다.
3. 버튼을 누르면 북마크가 즉시 추가되거나 해제된다.
4. 저장에 실패하면 이전 상태로 돌아가고 재시도 가능한 오류 메시지를 보여준다.

비로그인 사용자에게도 버튼은 보이되, 클릭하면 로그인이 필요하다는 안내와 로그인 이동 수단을 제공한다. 로그인 후 원래 게시글로 돌아올 수 있어야 한다.

### 북마크 목록

1. 사용자가 마이페이지의 `북마크` 영역으로 이동한다.
2. 본인이 북마크한 게시글을 최근 북마크순으로 본다.
3. 항목을 선택하면 해당 게시글 상세 화면으로 이동한다.
4. 북마크가 없으면 빈 상태 안내를 보여준다.

## 4. 기능 요구사항

### 게시글 상세

- 버튼은 `북마크 추가`와 `북마크 해제` 상태를 아이콘과 텍스트 또는 접근 가능한 이름으로 구분한다.
- 초기 상태를 불러오는 동안 잘못된 상태가 잠깐 표시되지 않도록 로딩 상태를 제공한다.
- 클릭 결과는 낙관적으로 반영할 수 있지만, 요청 실패 시 원래 상태와 React Query 캐시를 복구한다.
- 빠른 연속 클릭으로 중복 레코드나 최종 상태 불일치가 생기지 않아야 한다.
- 같은 사용자는 같은 게시글을 한 번만 북마크할 수 있다.

### 마이페이지

- 각 항목에 게시글 제목, 목록에서 기존에 사용하는 요약 정보, 북마크한 시각을 표시한다.
- 목록은 `bookmarks.created_at` 내림차순으로 정렬한다.
- 게시글이 삭제되면 해당 북마크도 제거되어 목록에 노출되지 않는다.
- 목록 조회 실패 시 오류 안내와 재시도 동작을 제공한다.
- 항목에서 북마크를 해제할 경우 목록과 게시글 상세의 캐시가 함께 갱신된다.

## 5. 데이터 모델 및 권한

Supabase에 다음 구조의 `bookmarks` 테이블을 둔다.

| 필드 | 타입 | 규칙 |
| --- | --- | --- |
| `id` | `uuid` | 기본 키, 자동 생성 |
| `user_id` | `uuid` | `auth.users.id` 외래 키, 필수 |
| `post_id` | 게시글 PK와 동일 | 게시글 외래 키, 필수, 게시글 삭제 시 cascade |
| `created_at` | `timestamptz` | 서버 기본값 `now()`, 필수 |

- `(user_id, post_id)`에 unique 제약을 둔다.
- `user_id`와 `created_at`, 필요 시 `post_id` 조회에 맞는 인덱스를 둔다.
- Row Level Security를 활성화한다.
- 인증 사용자는 `auth.uid() = user_id`인 행만 조회, 추가, 삭제할 수 있다.
- 추가 시 클라이언트 입력만 신뢰하지 않고 현재 인증 사용자를 소유자로 검증한다.
- 다른 사용자의 북마크 존재 여부와 목록은 노출하지 않는다.

## 6. 앱 연동

- Next.js 15 App Router의 기존 인증 및 게시글 상세/마이페이지 구조를 따른다.
- Supabase 요청은 기존 프로젝트의 서버/클라이언트 경계와 세션 처리 방식을 재사용한다.
- React Query는 북마크 여부, 추가/해제 mutation, 마이페이지 목록을 관리한다.
- mutation 성공 후 관련 북마크 여부와 목록 쿼리를 갱신하거나 무효화한다.
- 인증되지 않은 요청, 존재하지 않는 게시글, 권한 위반, 중복 추가를 구분해 처리하되 내부 오류 정보는 사용자에게 노출하지 않는다.

## 7. 완료 조건

- 로그인 사용자가 게시글 상세에서 북마크를 추가하면 버튼 상태가 바뀌고 새로고침 후에도 유지된다.
- 북마크한 게시글이 마이페이지에 최근 북마크순으로 표시되고 상세 화면으로 이동할 수 있다.
- 사용자가 북마크를 해제하면 상세 버튼과 마이페이지 목록에 반영되며 새로고침 후에도 유지된다.
- 동일한 게시글을 반복해서 북마크해도 중복 데이터가 생성되지 않는다.
- 비로그인 사용자는 북마크 데이터를 만들거나 읽을 수 없으며 로그인 안내를 받는다.
- 사용자는 다른 사용자의 북마크를 조회하거나 변경할 수 없다.
- 로딩 중 중복 요청이 방지되고, 실패 시 UI와 캐시가 서버 상태에 맞게 복구된다.
- 키보드와 스크린 리더로 버튼의 상태와 동작을 확인하고 실행할 수 있다.
